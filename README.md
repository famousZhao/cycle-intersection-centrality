> **Cycle-Intersection Centrality: A High-Order Topological Metric for
> Identifying Cycle-Structure Control Nodes in Complex Networks**

This package re-derives every figure, table, and numerical claim in the paper:
pinned datasets with SHA-256 checksums, metric definitions, the experiment suite,
and the reference results file.

This repository contains the exact code and data used for the **six-network**
version of the paper. Two additional datasets (Euroroads and a yeast
protein-interaction network) are included in the pipeline for completeness but
are not reported in the paper's figures or tables.
